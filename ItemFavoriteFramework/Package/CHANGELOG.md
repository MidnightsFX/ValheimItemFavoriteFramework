**0.0.1**
```
- Initial release.
- Favorite items (weapons, armor and tools individually; stackables by type), favorite inventory slots, and flag items as trash.
- Woven slot borders that show both colours when a favorite item sits in a favorite slot, greyed-out trash icons, and tooltip lines, following Quick Stack Store Sort's controls and colours.
- Vanilla "Place stacks" leaves protected items in your inventory. Optionally, trash is not auto-picked up.
- One-time import of Quick Stack Store Sort favorites per character.
- Public API (ItemFavoriteFramework.API) and a soft-dependency shim (ItemFavoriteFrameworkAPI) for other mods.
- Other mods can add their own item marks with their own colours and icons, and react to clicks on inventory items.
- Adds a wishlist: items you want are highlighted wherever they appear, and you're told when one drops nearby.
- On servers running the mod, players can see each other's wishlists.
- Adds need/greed/pass loot rolls, run by the server, for drops other mods hand over, with a roll window and chat commands.
```
